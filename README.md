# E-Commerce-Sales-Analysis-PowerBI
Power BI project for analyzing e-commerce sales data using data transformation, data modeling, relationships, Power Query, and interactive visualizations. The project includes order, order details, and sales target analysis with profit margin, profit status, regional, category, and monthly sales insights.

E-Commerce Sales Analysis using Power BI
